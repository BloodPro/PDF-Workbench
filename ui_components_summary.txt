UI STANDARDIZATION REFACTORING - SUMMARY
=========================================

THREE NEW COMPONENTS ADDED:

1. PlacementBuilder (Class)
   Location: Before PDFPartner class (around line 800)
   Purpose: Unified placement UI builder for overlay operations
   Saves: ~150 lines of duplicated code
   Used by: Text Overlay, Sign/Stamp, and future positioning modules
   
   Methods:
   - __init__(parent, app, pos_var, mx_var, my_var, cx_var, cy_var)
   - build(title="Placement", show_pages=True, pages_var=None)
   - _rebuild_detail() [private]
   
   QUICK USAGE:
   ```
   builder = PlacementBuilder(left, self, pos, mx, my, cx, cy)
   place_grp = builder.build(show_pages=True, pages_var=pages)
   ```

2. ButtonBar (Class)
   Location: Before PDFPartner class
   Purpose: Standardized button bar with consistent spacing
   Used by: All 11 modules for action buttons
   
   Methods:
   - __init__(parent, padding=(12, 0))
   - add_left(text, command, padx=3)
   - add_right(text, command, padx=3, primary=False)
   - add_center(text, command, padx=3) [optional]
   
   QUICK USAGE:
   ```
   actions = ButtonBar(body)
   actions.add_left("Clear", clear_fn)
   actions.add_right("Apply", apply_fn)
   ```

3. MODULE_OUTPUT_SUFFIXES (Dictionary)
   Location: After IF_EXISTS_OPTIONS constant (around line 92)
   Purpose: Single source of truth for module output file naming
   Maps: Module identifiers → Default output suffixes
   
   QUICK USAGE:
   ```
   suffix = MODULE_OUTPUT_SUFFIXES.get("page_numbering", "")
   ```

4. UIMessenger (Class) [OPTIONAL - For Future]
   Location: Before PDFPartner class
   Purpose: Centralized error, warning, info messaging
   
   Methods:
   - error_validation(message, parent=None)
   - error_file(filename, exc, parent=None)
   - error_runtime(title, exc, include_traceback=False, parent=None)
   - success(title, message, parent=None)
   - success_files(count, parent=None)
   - warning(title, message, parent=None)
   - warning_with_details(title, count_done, count_errors, details_location, parent=None)
   - confirm(title, message, parent=None)
